# learnhub

A new Flutter project.

## Interview Preparation

The interview section includes 400 questions across Python Programming, SQL /
Database Management, Machine Learning, Data Science, Generative AI, Agentic AI,
Azure DevOps, and Data Engineering. Each subject contains 20 basic,
20 intermediate, and 10 advanced questions with answers, examples, use cases,
and interview notes.

Questions can be searched and filtered by difficulty, reviewed with previous
and next navigation, bookmarked, marked complete, and revisited from saved and
recently viewed lists. Bookmarks, completion, and recent-question history are
stored locally on the device.

## Certificates and Settings

The Profile page links to Certificates and Settings. Course certificates are
created only after every lesson in that course is complete; assessment
certificates require a score of at least 70%. Earned certificates are stored
locally and can be previewed, saved/printed as PDFs, or shared.

Settings persist the learner profile, theme, notification preferences, learning
subjects, daily goal, and language on the device. A changed local password is
kept in the platform secure-storage service. Delete Account requires
confirmation and clears the locally stored LearnHub profile, password,
preferences, course progress, interview progress, and certificates.

## Local Accounts and Greetings

Registration collects a full name, email, and password. Local accounts are
distinguished by normalized email addresses; passwords are stored in the
platform secure-storage service. The Home greeting and Profile name follow the
signed-in account, and name changes also update saved certificates. Guest mode
uses the name-free “Welcome!” greeting. Account data remains on the device and
is not sent to a LearnHub server.
